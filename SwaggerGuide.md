# Swagger / OpenAPI Guide

The service exposes Swagger UI and the OpenAPI document for local development.

## Access
- Swagger UI: http://localhost:8080/swagger-ui.html
- OpenAPI JSON: http://localhost:8080/v3/api-docs

## What you can do
- Explore the available REST endpoints
- Try the create, list, get, delete, resolve, and analytics requests interactively
- Review request and response models

## Notes
- The service uses springdoc-openapi with the default Spring Boot webmvc setup.
- If you run the app locally, the documentation is available automatically.
